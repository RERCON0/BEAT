BEAT — лёгкое нативное Windows-приложение на Rust. Подключите
[Navidrome](https://www.navidrome.org/) или добавьте свои папки музыки.
Скачанные треки остаются обычными файлами; локальный плеер работает без сервера.

## Возможности

| | Что умеет BEAT |
|---|---|
| **Лёгкость** | Нативное приложение на Rust со встроенными шрифтами и кодеками; один портативный EXE |
| **Автокеширование Navidrome** | Треки сохраняются в фоне при воспроизведении; завершённые загрузки доступны без сети. Включите автокеширование новых песен, чтобы сохранять и будущие пополнения сервера |
| **Общая библиотека** | Серверные песни, загрузки и до 16 локальных папок в одном списке; быстрый фильтр по названию, артисту и альбому |
| **Обзор и поиск** | Артисты, альбомы, встроенные обложки и поиск на сервере и диске |
| **Очередь воспроизведения** | Открывается из строки состояния; выбор трека, перестановка, удаление или сохранение только текущего трека |
| **Подготовка следующей песни** | Следующий локальный или полностью скачанный трек готовится для перехода без паузы; серверный — заранее скачивается в пределах лимита загрузок |
| **Управление Windows** | Системные медиакнопки и совместимые клавиатуры/гарнитуры: воспроизведение, пауза, назад и вперёд, в том числе при свёрнутом окне |
| **Продолжение с места остановки** | Последний трек, позиция внутри него, очередь, случайный порядок и повтор восстанавливаются; воспроизведение начинается по нажатию **▶** |
| **Загрузки** | Один трек, альбом или вся библиотека; до трёх загрузок одновременно; автокеширование новых песен по желанию |
| **Без сети, на двух языках** | Свои файлы и готовые загрузки работают без сервера; тёмная/светлая темы и сохраняемый переключатель EN/RU в шапке |
| **Защита** | DPAPI для паролей, разделение аккаунтов, ограничения редиректов и путей, лимиты обработки медиа и обложек; CI и проверки безопасности |

Поддерживаются MP3, FLAC, OGG/Vorbis, **Opus** (моно/стерео в Ogg/WebM), WAV
и распространённые варианты AAC/M4A/MP4. Opus-декодер встроен. Воспроизведение
начинается после буферизации; перемотка при загрузке доступна в пределах уже
полученных данных.

> [!IMPORTANT]
> Для перехода без паузы следующий файл должен быть готов вовремя. Медленный
> сервер или незавершённая загрузка могут потребовать буферизации. Тишина,
> которая уже есть в самой записи, сохраняется.

## Быстрый старт

### С Navidrome

1. Откройте **Настройки**, укажите адрес сервера, логин и пароль.
2. Нажмите **Проверить связь**, затем **Сохранить**.
3. Откройте библиотеку, альбом или поиск. **▶** играет, **↓** скачивает.

Адрес может включать подпапку, например `https://music.example.com/library`;
дописывать `/rest` не нужно. Для удалённого сервера требуется HTTPS, HTTP
допускается только для `localhost` и loopback-адресов.

> [!TIP]
> Автокеширование сначала запоминает существующие песни, затем скачивает новые.
> Чтобы забрать всю библиотеку сейчас, нажмите **↓ скачать все песни**.
> Уже скачанные треки пропускаются.

### Со своей музыкой

1. Откройте **Настройки** и добавьте папки музыки. Файлы остаются на своих местах.
2. Откройте **Библиотеку**, при необходимости нажмите **Обновить**. Подпапки учитываются.
3. Нажмите **▶**; счётчик очереди в строке состояния открывает список воспроизведения.

По умолчанию кеш хранится в системной папке **Музыка → BEAT**; её можно сменить.
Туда можно положить и свои файлы. Личная музыка не отправляется в Navidrome;
очистка кеша затрагивает только загрузки, записанные в индекс BEAT.

Кнопка **RU / EN** в шапке переключает язык, **день / ночь** — тему.
Оба выбора сохраняются после перезапуска.

## Сборка

Платформа — **Windows x64**. Нужны Rustup, Visual Studio Build Tools с C++
и Windows SDK, CMake 3.16+ для встроенного libopus. Для запуска требуются
OpenGL 2.1+ и устройство вывода звука. Rust закреплён в
[rust-toolchain.toml](rust-toolchain.toml).

Из корня репозитория в PowerShell:

```powershell
cargo build --locked --release --bin beat
.\target\release\beat.exe
```

Сервер и музыка для сборки не требуются. Иконка, шрифты и Opus-декодер
встроены; EXE запускается из Проводника. MSVC линкуется статически,
Visual C++ Redistributable не нужен.

> [!NOTE]
> Сборки пока не имеют Authenticode-подписи. SmartScreen может предупредить
> о неизвестном приложении. Если вы доверяете источнику сборки, выберите
> **Подробнее → Выполнить в любом случае**. SHA-256 сам по себе не подтверждает издателя.

## Настройки и данные

| Где | Что хранится |
|---|---|
| `%APPDATA%\beat` | Настройки, язык, последний трек и позиция, очередь, история прослушиваний, списки сервера |
| `%APPDATA%\beat\covers` | Ограниченный кеш миниатюр |
| **Музыка → BEAT** или выбранная папка кеша | Загрузки и отдельные индексы `.beat-index-*.json` |
| Дополнительные папки музыки | Ваши исходные аудиофайлы; BEAT читает их на месте |

Пароль защищён Windows DPAPI текущего пользователя. Загрузки, серверные
списки и обложки разделены по серверу и аккаунту; история и сессия также
учитывают папку кеша. Файлы прежнего аккаунта доступны как локальная музыка.
Очистка кеша удаляет только индексированные загрузки текущего аккаунта.
Удаление папки из настроек не удаляет её файлы. Повреждённые данные сохраняются
для восстановления; ошибки чтения и записи видны в приложении.

> [!CAUTION]
> Незавершённые `*.part` после аварийного закрытия проверяйте и удаляйте только
> при закрытом BEAT. Не передавайте другим свои настройки и пароль сервера.

## Разработка

```powershell
cargo fmt --all -- --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked --all-targets
python -B scripts/check_docs.py
python -B scripts/update_i18n.py --check
```

CI проверяет код, переводы, документацию и оптимизированную Windows-сборку.
Security ежедневно проверяет Cargo.lock и сканирует всю историю Git на секреты.
Actions закреплены полными SHA; Dependabot предлагает обновления еженедельно.
Артефакт CI содержит неподписанный EXE, SHA-256, исходный коммит и уведомления компонентов.
