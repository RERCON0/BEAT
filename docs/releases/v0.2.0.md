BEAT 0.2.0 is a lightweight Windows player with automatic Navidrome caching, local music, an editable queue and EN/RU. Stream a track and BEAT saves it in the background for offline listening once the download finishes. Automatic caching of new server songs can also save future library additions.

### What's new

- Windows system media controls and compatible keyboard/headset buttons, including while minimized.
- Restore the last track and its playback position after restart; playback begins when you press play.
- Editable queue: select, reorder, remove tracks or keep only the current track.
- Up to 16 local music folders with shared scanning limits and no duplicates from overlapping folders.
- Next-track preparation and gapless playback for ready local/cached files; server predownloads respect the download limit.
- Saved EN/RU switch in the title bar, English and Russian READMEs, and screenshots of both themes.
- Built-in Opus playback in Ogg/WebM, mono and stereo. No separate codec installation.

### Fixes and checks

Cover thumbnails keep their proportions. State, cache and downloaded files are scoped to the server/account; malformed media, cover parsing and paths have bounds and validation. Queue changes, buffering, seeking and track transitions received additional regression tests.

158 automated tests pass. Windows CI checks Clippy, tests, the optimized EXE and its ASLR/DEP/static runtime. Security scans RustSec dependencies and the full Git history for secrets. See the [audit report](https://github.com/RERCON0/BEAT/blob/v0.2.0/docs/AUDIT-2026-10-07.md) for details and limits.

### Download

Download **beat.exe** below and run it on **Windows 10/11 x64** with OpenGL 2.1+ and an audio output device. To update, close BEAT and replace the old EXE; settings and music stay in their existing locations.

The build has no Authenticode signature. SmartScreen may warn about an unknown app; if you trust the source, select **More info → Run anyway**. `SHA256SUMS.txt` verifies file integrity, `BUILD.json` records the source revision, and `COMPONENT-NOTICES.txt` includes bundled component notices.

Gapless playback requires the next file to be ready. A slow server can still require buffering; silence already in a recording is preserved.
