BEAT 0.2.1 keeps the lightweight Windows player, automatic Navidrome caching and offline library, while improving its maintenance foundation.

### Changes

- Portable ZIP signed with Ed25519. The manifest covers every payload file and records its source commit, toolchain and lockfile. [Verification and trusted key](https://github.com/RERCON0/BEAT/blob/v0.2.1/docs/RELEASING.md).
- GNU GPL v3 or later, matching SNATCH; license and bundled component notices included.
- Split startup, application controllers, worker events, UI screens and cache operations into focused modules. Buttons emit typed commands applied after drawing.
- Upgrade eframe/egui to 0.36.2, reqwest to 0.13.5 and Rust to 1.99.0. Remove the old ttf-parser maintenance warning while retaining Windows Schannel.
- Keep Rodio/Symphonia/Opus on a compatible family, with the media allocation guard intact; separate Dependabot groups and document the audio migration gate.
- Use a consistent static MSVC runtime for Rust and bundled libopus. Process background state in the lifecycle hook that also runs while minimized.

159 Rust tests and 12 signature/tamper tests pass. Windows CI checks Clippy, tests and the optimized native EXE; Security scans the full dependency lockfile and Git history. [Maintenance audit](https://github.com/RERCON0/BEAT/blob/v0.2.1/docs/AUDIT-2026-10-08.md).

### Download

Download **beat-windows-x64.zip**, verify it using the trusted checkout if desired, extract it and run **beat.exe**. Windows 10/11 x64, OpenGL 2.1+ and an audio output device are required. To update, close BEAT and replace its program files; settings and music remain in their existing locations.

Ed25519 signs the package; it is **not Authenticode**. SmartScreen may still warn. If you trust the source, select **More info → Run anyway**. CI candidates and the standalone EXE have no package signature. Release 0.2.0 remains unsigned.

### Русский

В 0.2.1 добавлены подпись ZIP Ed25519 и GPL v3 или новее. Контроллеры, события, команды, экраны и кеш разделены на отдельные модули. Обновлены графический и сетевой стек, убрано предупреждение старого ttf-parser; совместимый аудиостек и его защитный патч сохранены. Фоновые события обрабатываются и при свёрнутом окне.

Скачайте ZIP, распакуйте и запустите `beat.exe`. Подпись пакета не является Authenticode и не отключает SmartScreen. Если доверяете источнику, выберите «Подробнее → Выполнить в любом случае». Настройки и музыка при замене программы сохраняются.
