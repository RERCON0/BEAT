BEAT 0.2.2 improves connections to a home-network Navidrome server, fixes narrow-panel layout problems and refreshes compatible dependencies. Automatic Navidrome caching, offline playback and local music remain the core workflow.

## Changes since the last published release, 0.2.1

- **Connect to a LAN Navidrome over HTTP.** Accept plain HTTP for localhost/loopback, RFC 1918 private IPv4, `100.64.0.0/10` (CGNAT/Tailscale), link-local IPv4/IPv6, IPv6 unique-local addresses, single-label hostnames and the recognized local suffixes `.local`, `.lan`, `.home`, `.home.arpa`, `.internal`, `.localdomain` and `.intranet`. Public literal IP addresses and ordinary public domain names still require HTTPS. Redirects remain confined to the configured origin.
- **Document the hostname boundary accurately.** Local-looking names are checked by spelling, not DNS resolution. BEAT does not claim to verify that such a name resolves to a private address. Plain HTTP is unencrypted; use it only on a network you trust, or use HTTPS.
- **Keep settings buttons usable.** Connection results and configuration-save errors have their own wrapped rows above the buttons. A long error no longer runs under **Save** and **Cancel**. Regression tests cover long messages and button placement.
- **Keep the library filter summary inside its panel.** Long filter/selection summaries wrap instead of pushing content outside the library panel. A layout regression test covers the narrow-panel case.
- **Compatible dependency refresh.** Update the lockfile, including `serde_json` 1.0.154, TOML 1.1.8, UUID 1.28.0 and supporting crates. Update the CI artifact uploader to 7.0.2 and separate scheduled security runs from push checks.
- **Preserve the tested audio family.** Rodio 0.22.2, Symphonia 0.5.5 and the Opus adapter remain together, with the media-allocation guard intact. Symphonia 0.6 is held until the complete decoding stack and the guard can migrate together; no audio-format expansion is claimed for this release.
- **English/Russian documentation and messages** reflect the LAN HTTP rule and the settings fixes.

The already updated eframe/egui 0.36.2, reqwest 0.13.5 and Rust 1.99.0 foundation is retained. Those upgrades were part of 0.2.1, not new changes in this release.

## Download and update

Download **beat-windows-x64.zip**, extract it and run **beat.exe**. Windows 10/11 x64, OpenGL 2.1+ and an audio output device are required. Add your Navidrome server or local music folders in Settings; cached tracks remain available for offline listening.

To update, close BEAT and replace its program files. Existing settings, local music and downloaded cache remain in their existing locations.

The ZIP carries an **Ed25519-signed manifest** using the existing BEAT publisher key. It is **not Authenticode**; Windows SmartScreen may still warn. The standalone EXE and unsigned CI candidates do not carry the package signature.

## Русский

BEAT 0.2.2 включает все изменения после последнего опубликованного 0.2.1. Домашний Navidrome теперь можно подключать по HTTP через приватные и локальные IP, адреса Tailscale/CGNAT и локальные имена. Публичные IP и обычные публичные домены по-прежнему требуют HTTPS; перенаправления не выходят за настроенный origin.

Локальные имена проверяются по написанию, без DNS-проверки конечного адреса. HTTP не шифрует соединение, поэтому используйте его только в доверенной сети или настройте HTTPS.

Длинные ошибки связи и сохранения настроек больше не перекрывают кнопки «Сохранить» и «Отмена». Сводка фильтра библиотеки переносится внутри панели вместо выхода за её границы. Эти сценарии покрыты проверками вёрстки. Обновлены совместимые зависимости и CI; аудиостек Rodio/Symphonia/Opus и защитный патч сохранены.

Для обновления закройте BEAT и замените файлы программы. Настройки, музыка и кеш сохраняются. Автокеширование Navidrome и офлайн-прослушивание работают как раньше. ZIP подписан прежним ключом Ed25519; это не Authenticode и не отменяет SmartScreen.
